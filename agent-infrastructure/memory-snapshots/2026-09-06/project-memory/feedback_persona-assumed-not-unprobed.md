When recalibrating a coach or agent persona toward an experienced learner, do not write "do not re-examine fundamentals." Write: assume working familiarity, do not reteach by default, probe or refresh when the learner's reasoning exposes a gap or when the new domain (here AI/non-determinism) materially changes how the practice applies.

**Why:** User correction 2026-09-05 on the ai-pd-tracker persona v3: "don't overcorrect away from PM fundamentals … part of the curriculum is still to refresh Product craft and expose any gaps." My first draft over-rotated from the novice framing to a no-probe framing.

**How to apply:** Persona text should name the probe trigger, not just the default. Keep the complementary rule: a textbook-correct answer in the assumed domain that fails to adapt to the new domain is a HOLD, not a PASS. Related: [[avoid-profile-anchoring]].
